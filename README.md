# 家庭 DIY 项目规划与材料管家

纯前端的家庭 DIY 项目管理应用，帮助用户管理工具库存、材料库存，规划 DIY 项目并分析库存缺口。

## 技术栈

- Vue 3（`<script setup>` + TypeScript）
- Vite
- Element Plus（UI 组件库）
- Vue Router（路由）
- 组合式 Store（`reactive` + `localStorage` 持久化，无额外状态库）

## 功能

- **工具库存**：名称、类别、数量、存放位置、状态（完好/需维修/已借出）、照片（base64）
- **材料库存**：名称、类别、数量、单位、最低库存预警值、存放位置
- **DIY 项目**：名称、类别、描述、预计工时、难度、所需工具/材料清单（从库存选择或手动添加）
- **库存缺口分析**：计算属性对比库存，生成待采购/待借用清单并高亮缺口数量
- **项目状态**：规划中/进行中/已完成/已搁置；进行中记录实际用时与花费，完成后上传成果照片与总结
- **自评与反馈**：1-5 星自评、工具是否够用、材料是否浪费
- **库存预警面板**：自动列出低于最低库存的材料
- **工具借还记录**：借用人、借出/预计归还/实际归还日期，未归还在首页提醒
- **数据看板**：工具总数、材料种类、进行中项目、本月完成项目、库存预警
- **排行榜**：DIY 达人榜（完成数及难度加权）、工具管理大师榜（完好率与借还准时率综合）
- **个人中心**：我的工具/材料/项目/借还记录、12 种成就徽章（条件达成自动解锁）

## 运行

```bash
npm install
npm run dev       # 开发
npm run build     # 类型检查 + 构建
npm run preview   # 预览构建产物
```

## 目录结构

```
src/
├── types/        # 领域模型与常量
├── utils/        # localStorage 封装、ID、日期、图片压缩
├── stores/       # 组合式 Store（工具/材料/项目/借还/成就）
├── composables/  # 派生数据（看板/排行榜）
├── router/       # 路由
├── components/   # 可复用组件
└── views/        # 页面
```

## 数据存储

所有数据保存在 `localStorage`（`diy.*` 键）。图片统一压缩为 JPEG base64 以控制体积。
